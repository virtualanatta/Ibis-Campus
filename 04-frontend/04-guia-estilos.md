# Guía de estilos

## Colores

```css
:root {
  --primary:   #3498db;
  --secondary: #2ecc71;
  --danger:    #e74c3c;
  --warning:   #f39c12;
  --dark:      #2c3e50;
  --light:     #ecf0f1;
}
```

## Tipografía

```css
:root {
  --font-primary: 'Segoe UI', system-ui, sans-serif;
  --font-size-base: 16px;
  --font-weight-normal: 400;
  --font-weight-bold: 600;
}
```

## Componentes base

`Button`, `Input`, `Card`, `Modal`, `Badge` y `Alert`, construidos sobre estas variables para mantener un aspecto uniforme entre vistas.
